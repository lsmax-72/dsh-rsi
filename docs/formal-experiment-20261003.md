## 授权与固定方案

## 执行入口

prepare-task-image.py 复用固定官方评分包，逐题下载 amd64 评分镜像、核对 base tree 与实际 HEAD 时间。任务镜像仅复制公开 task.json、基础代码和已验证官方宿主；隐藏测试与答案仅留在评分侧。评分镜像与宿主本地标签绑定真实 image ID，构建前后核对，执行时再次核对任务 image ID。

run-paired.py 复用既有单次隔离运行器、共享预算、官方评分和离线汇总。启动时冻结源码、构建产物、依赖描述、题单与模型服务地址哈希。前序顺序累积原生资产与来源日志；后序每题独立复制同一最终前序状态，按预定顺序交错两组。不在提示中指定插件 Skill。

每次执行单独保存请求、usage、停止原因、前台墙钟、补丁、资产和来源日志。两组都检查网关计数、thinking off 与消息角色；环境尚未进入任务时的空补丁不算失败。服务错误、日志不一致或无评分报告停止扩量，先核查故障，不盲目重试、删题或改变固定分母。--resume 仅支持继续已判分执行之后的准备中断；未分类尝试需要先审核。
