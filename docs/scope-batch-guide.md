# 后台批跑与集中分析

2026-10-08。`scripts/run-scope-study.py` 是范围质量诊断的薄编排层，调用现有 `probe-runner.py`、隔离容器和原生学习/消费入口。没有新增记忆算法或模型服务。已存在的正式配对、PersonaMem、连续编程入口分别为 `run-paired.py`、`run-personamem-study.py`、`run-continuous-study.py`；它们本来就能按冻结题单批跑，本次补齐最近临时范围诊断的后台入口、固定并发和自动审计。

## 哪些可以并行

| 工作 | 并行边界 |
| --- | --- |
| 本次范围质量案例 | 独立容器、独立资产库，可固定2路并行；本脚本支持1–3路 |
| PersonaMem | 可按独立用户编排并行；本次没有修改其现有串行脚本 |
| 连续编程学习 | 同一序列必须N→N+1，才能保留自然资产传递；独立序列可另行登记并行 |
| 同一案例的旧历史、新历史、消费者 | 保持阶段顺序，不能同时执行 |

并行可能缩短总等待时间，不保证按并发数等比例提速；共享qwen吞吐、容器构建与CPU/内存会成为限制。并发数随协议冻结，运行中不修改。下一轮先用2路，时间和错误率纳入诊断；已有串行成绩保持原口径。

## 一次启动，后台完成

先完成资产一致性、派生来源与无效工具往返修正，再登记新的开发诊断题单和预算。以下是下一轮使用方式，**当前没有启动新的真实qwen实验**。`RSI_MODEL_UPSTREAM` 沿用已经授权的服务，由本地环境配置；不在文档或命令中写入密钥。

```sh
# 项目目录下操作；先构建、提交并保持清洁代码。
python3 -B scripts/run-scope-study.py freeze \
  --spec <已审阅的新协议JSON> --output .artifacts/<新批次> --workers 2
python3 -B scripts/run-scope-study.py plan --output .artifacts/<新批次>
python3 -B scripts/run-scope-study.py start --output .artifacts/<新批次>
```

`freeze`固定代码修订、源文件哈希、镜像、模型端点哈希、公开输入、预算与并发数，不发模型请求。`plan`列出实际命令及批次最大调用数。`start`通过独立系统会话启动有限后台进程，标准输入断开，输出写入 `background-*.log`，立即返回PID与日志位置。该进程直接调用qwen，不需要Codex一题题触发，也不需要持续开启模型回合轮询。零模型测试已验证：启动它的父进程退出后，子进程仍完成文件写入；没有验证操作系统强制结束全部进程后的存活能力。

后台自动执行案例，核对实际日志重建、模型交付和成本，保存 `batch-state.json`、每例原始日志、`case-audits/`、`batch-review-*/batch-report.json` 及正文消费证据。即使异常停止，也尽量汇总已保存调用和未知usage，不把缺失账单当成0。内容语义正确性保持 `REVIEW_REQUIRED`，完成率不能自动升级为质量成绩。后台不再调用Codex做语义评审；之后有额度时一次性读取报告和异常案例即可。

## 额度、中断和恢复

- **Codex对话额度耗尽**：已启动的独立实验进程不依赖后续Codex响应，仍能继续调度和保存报告；它消耗的是qwen服务与本机资源。
- **qwen返回额度不足、限流、网络错误或未知失败**：不自动重试、不加预算，停止派发新案例；已启动案例按自身上限结束、导出证据。并行下最多保留已派发的1–3个案例，不能宣称发现故障时所有远端调用立即消失。
- **预先规定的案例学习预算耗尽**：关闭该例、保留失败与费用，完成机制核对后可运行其余已登记独立案例。与qwen服务故障分开处理。
- **机器休眠、关机、Docker停止**：后台并非远程托管服务；执行可能暂停或中断。状态不明的案例不会自动重新开始。需要核对保存现场后再决定后续动作。
- **后台启动额度也没有了**：必须先有一个成功启动的进程；此脚本不能在从未启动的情况下自行运行。启动命令也可由用户在终端执行。

```sh
# 查询本地状态，不调用模型，不持续轮询。
python3 -B scripts/run-scope-study.py status --output .artifacts/<批次>
# 请求当前在运行案例结束后不再启动下一例。
touch .artifacts/<批次>/STOP
# 确认恢复时移除STOP，再继续尚未启动的案例；不会重跑已关闭的案例。
rm .artifacts/<批次>/STOP
python3 -B scripts/run-scope-study.py start --output .artifacts/<批次> --resume
```

若有 `RUNNING`、`NEEDS_AUDIT` 或 `HALTED` 案例，恢复被拒绝，防止断点不明时重复花费；必须先检查对应现场。`batch.lock`排除重复启动，强制杀进程留下的锁需先确认PID及进程已结束，再人工处理；脚本不擅自删他人的活跃锁。无异常的已关闭前缀可恢复未启动后缀。改变代码、模型端点、镜像、题目或预算时，必须使用新批次；旧失败仍保留。
